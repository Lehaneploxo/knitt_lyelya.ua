## 🎯 КРАТКОЕ РЕЗЮМЕ

**Проблема:** Онлайн оплата через Monobank не работает на production сайте.

**Причина:** Переменные окружения в Vercel содержат лишние символы новой строки (`\n`) в конце значений.

**Решение:** Переустановить переменные окружения без лишних символов.

---

#### ❌ 3. Переменные окружения - ПРОБЛЕМА!

При проверке production переменных обнаружено:

```env
MONOBANK_TOKEN="mEV7ptuaG1LcHiw1viKbAaQ\n"
NEXT_PUBLIC_BASE_URL="https://www.knittlyelyaua.com\n"
SHOP_NAME="knitt_lyelya.ua\n"
```

**Видите `\n` в конце?** Это символ новой строки!

### ПОЧЕМУ ЭТО ПРОБЛЕМА:

Когда ваш код делает запрос к Monobank API:

```javascript
headers: {
  'X-Token': process.env.MONOBANK_TOKEN  // = "mEV7ptuaG1LcHiw1viKbAaQ\n"
}
```

Monobank получает токен с лишним символом и отклоняет запрос!

То же самое с webhook URL:
```javascript
webHookUrl: `${process.env.NEXT_PUBLIC_BASE_URL}/api/payment/webhook`
// = "https://www.knittlyelyaua.com\n/api/payment/webhook" <- НЕПРАВИЛЬНЫЙ URL!
```

## 🆘 TROUBLESHOOTING

### Проблема 1: Скрипт не запускается

**Ошибка:** `node: command not found`

**Решение:** Установите Node.js:
- Скачайте: https://nodejs.org/
- Установите версию LTS
- Перезапустите терминал

---

### Проблема 2: Vercel CLI не авторизован

**Ошибка:** `Error: Not authorized`

**Решение:**
```bash
vercel login
```

Следуйте инструкциям для входа.

---

### Проблема 3: После redeploy всё равно не работает

**Проверьте:**

1. **Переменные добавлены правильно:**

3. **Кеш очищен:**
   - Откройте сайт в режиме инкогнито
   - Или очистите кеш браузера (Ctrl+Shift+Del)

4. **Проверьте логи:**
   - Dashboard → Functions → api/payment/create-invoice
   - Посмотрите последние вызовы и ошибки
