# Інструкція з налаштування адмін-панелі

## Огляд функціоналу

Адмін-панель надає повний контроль над сайтом:

### 1. Аутентифікація
- Вхід за логіном та паролем
- Дані авторизації зберігаються в Sanity CMS

### 2. Управління головною сторінкою
- Зміна Баннер 1 та Баннер 2
- Зміна посилання на Instagram-пост

### 3. Каталог товарів
- Три розділи: Етно / Базовий / Дім
- Додавання нових товарів
- Редагування існуючих товарів (фото, опис, ціна)
- Видалення товарів
- Зміни миттєво відображаються на сайті

### 4. Контент
- Редагування тексту "Про бренд"

### 5. Замовлення
- Перегляд всіх замовлень
- Дані покупця, склад замовлення, сума
- Зміна статусу оплати (оплачен / не оплачен / часткова оплата)
- Email-сповіщення про нові замовлення

---

## Перше налаштування

### Крок 1: Створіть початкові дані в Sanity Studio

1. Запустіть проект:
```bash
npm run dev
```

2. Відкрийте Sanity Studio:
```
http://localhost:3000/studio
```

3. **ВАЖЛИВО!** Створіть документ налаштувань:
   - Натисніть "+ Create"
   - Виберіть "Налаштування / Settings"
   - Заповніть:
     - **Email для сповіщень**: your-email@example.com
     - **Логін адміністратора**: admin (або будь-який інший)
     - **Пароль адміністратора**: створіть надійний пароль (мінімум 6 символів)
   - Натисніть "Publish"

### Крок 2: Налаштуйте головну сторінку

1. У Sanity Studio натисніть "+ Create"
2. Виберіть "Головна сторінка / Home Page"
3. Завантажте:
   - Баннер 1 (основне зображення)
   - Баннер 2 (додаткове зображення)
   - Посилання на Instagram-пост (необов'язково)
4. Натисніть "Publish"

### Крок 3: Налаштуйте контент "Про бренд"

1. У Sanity Studio натисніть "+ Create"
2. Виберіть "Про бренд / About Brand"
3. Заповніть текст українською та англійською
4. Натисніть "Publish"

## Використання адмін-панелі

### Вхід в адмін-панель

1. Відкрийте:
```
http://localhost:3000/admin
```

2. Введіть логін і пароль, які ви створили в Sanity Studio
3. Натисніть "Увійти"

### Управління товарами

#### Додавання товару:
1. Перейдіть в Sanity Studio: http://localhost:3000/studio
2. Натисніть "+ Create" → "Товари / Products"
3. Заповніть:
   - Назва (українською та англійською)
   - Натисніть "Generate" біля поля URL
   - Артикул (наприклад: ETH-001)
   - Ціна
   - Категорія (Етно/Базові/Дім)
   - Опис
   - Фото (можна завантажити кілька)
   - Матеріали, кольори, розміри
4. Натисніть "Publish"

#### Редагування товару:
1. У Sanity Studio знайдіть потрібний товар
2. Відкрийте його
3. Змініть потрібні поля
4. Натисніть "Publish"

#### Зміна ціни окремо:
1. Відкрийте товар в Sanity Studio
2. Знайдіть поле "Ціна / Price (грн)"
3. Введіть нову ціну
4. Натисніть "Publish"

#### Зміна опису окремо:
1. Відкрийте товар в Sanity Studio
2. Знайдіть поле "Опис (українською)" або "Description (English)"
3. Введіть новий опис
4. Натисніть "Publish"

#### Видалення товару:
**Спосіб 1 (через адмін-панель):**
1. Перейдіть в адмін-панель: http://localhost:3000/admin
2. Знайдіть товар у списку
3. Натисніть "Видалити"
4. Підтвердіть видалення

**Спосіб 2 (через Sanity Studio):**
1. Відкрийте товар в Sanity Studio
2. Натисніть "..." (меню) → "Delete"
3. Підтвердіть видалення

### Перегляд замовлень

1. Увійдіть в адмін-панель
2. Натисніть "Замовлення" в навігації
3. Переглянете список всіх замовлень з:
   - Номером замовлення
   - Даними покупця (ім'я, email, телефон)
   - Складом замовлення
   - Сумою
   - Статусом оплати

### Зміна статусу оплати:

1. На сторінці замовлень знайдіть потрібне замовлення
2. У нижній частині замовлення є випадаючий список "Статус оплати"
3. Виберіть потрібний статус:
   - **Не оплачено** - клієнт ще не оплатив
   - **Часткова оплата** - клієнт оплатив частину суми
   - **Оплачено** - повна оплата отримана
4. Статус автоматично збережеться

### Редагування головної сторінки

1. Перейдіть в Sanity Studio: http://localhost:3000/studio
2. Знайдіть документ "Головна сторінка"
3. **Зміна баннера:**
   - Натисніть на поточне зображення баннера
   - Завантажте нове зображення
   - Натисніть "Publish"
4. **Зміна Instagram-поста:**
   - Скопіюйте посилання на пост з Instagram
   - Вставте в поле "Посилання на Instagram-пост"
   - Натисніть "Publish"

### Редагування тексту "Про бренд"

1. Перейдіть в Sanity Studio
2. Знайдіть документ "Про бренд"
3. Відредагуйте текст українською та/або англійською
4. Натисніть "Publish"

## Email-сповіщення про замовлення

### Налаштування email:

Email для сповіщень налаштовується в документі "Settings" у Sanity Studio.

**Як працює:**
1. Коли клієнт оформлює замовлення на сайті
2. Система автоматично створює запис в Sanity
3. На вказаний email відправляється сповіщення з даними замовлення

**ВАЖЛИВО:** Наразі email-сповіщення виводяться в консоль (логи сервера). Для повноцінної відправки email потрібно інтегрувати сервіс email-розсилки (SendGrid, Resend, або інший).

### Перегляд сповіщень у консолі:

1. У терміналі, де запущено `npm run dev`, ви побачите:
```
=== НОВЕ ЗАМОВЛЕННЯ ===
Email: your-email@example.com
Номер замовлення: 123456789
Покупець: Іван Петренко
...
```

## Структура розділів каталогу

### Етно
- Сумки з етнічними мотивами
- Український орнамент

### Базовий
- Класичні сумки
- Повсякденний стиль

### Дім
- Аксесуари для дому
- Декоративні елементи

**Як призначити товар до розділу:**
При створенні/редагуванні товару виберіть потрібну категорію в полі "Категорія / Category"

## Важливі примітки

### Безпека:

1. **Змініть стандартний пароль** одразу після першого входу
2. Використовуйте надійний пароль (мінімум 8 символів, цифри, букви)
3. Не діліться даними для входу

### Зображення:

- Рекомендований розмір баннерів: 1920x1080 пікселів
- Формат: JPG, PNG, WebP
- Максимальний розмір файлу: 5 МБ
- Для товарів: мінімум 1 фото, рекомендовано 3-5 фото

### Миттєве оновлення:

Всі зміни, зроблені в Sanity Studio, **миттєво** відображаються на сайті без необхідності перезапуску чи деплою.

## Часті питання

**Q: Чи можна змінити тільки ціну товару, не змінюючи опис?**
A: Так, відкрийте товар в Sanity Studio, змініть тільки поле "Ціна", і натисніть "Publish".

**Q: Як додати кілька фото до товару?**
A: В полі "Фото / Images" натисніть "+ Add item" для кожного нового фото.

**Q: Чи можна видалити замовлення?**
A: Так, через Sanity Studio. Знайдіть замовлення в розділі "Orders" і видаліть його.

**Q: Як змінити email для сповіщень?**
A: Відкрийте документ "Settings" в Sanity Studio, змініть email, і натисніть "Publish".

**Q: Чи можна працювати з адмін-панеллю з телефону?**
A: Так, Sanity Studio адаптивний і працює на мобільних пристроях, але рекомендовано використовувати комп'ютер.
