# Налаштування Gmail для відправки email

Цей файл містить детальні інструкції для налаштування відправки email через Gmail SMTP (Nodemailer).

## Що було реалізовано

1. ✅ Встановлено пакет `nodemailer` для відправки email
2. ✅ Оновлено `.env.local` з налаштуваннями Gmail
3. ✅ Оновлено обидва email endpoints для використання Gmail SMTP:
   - `/api/send-order-email` - для відправки на вашу пошту (власник)
   - `/api/send-payment-confirmation` - для відправки клієнту після оплати

## Налаштування Gmail App Password

### Крок 1: Увімкніть двофакторну автентифікацію (2FA)

**ВАЖЛИВО:** App Passwords доступні ТІЛЬКИ якщо увімкнена двофакторна автентифікація!

1. Перейдіть на https://myaccount.google.com/security
2. Знайдіть розділ "Вхід в обліковий запис Google"
3. Натисніть на "Двоетапна перевірка"
4. Увімкніть двоетапну перевірку (якщо ще не увімкнена)
5. Підтвердіть за допомогою телефону або іншим способом

### Крок 2: Створіть App Password

1. Після увімкнення 2FA, поверніться на https://myaccount.google.com/security
2. Знайдіть розділ "Вхід в обліковий запис Google"
3. Натисніть на "Паролі додатків" (App Passwords)

   **Якщо не бачите "Паролі додатків":**
   - Переконайтеся, що 2FA увімкнена
   - Зачекайте кілька хвилин після увімкнення 2FA
   - Спробуйте пряме посилання: https://myaccount.google.com/apppasswords

4. Виберіть додаток: **"Пошта"** (Mail)
5. Виберіть пристрій: **"Інший"** (Other)
6. Введіть назву: **"knitt_lyelya_website"** або будь-яку іншу
7. Натисніть **"Створити"** (Generate)
8. Google покаже 16-значний пароль (наприклад: `abcd efgh ijkl mnop`)
9. **СКОПІЮЙТЕ ЦЕЙ ПАРОЛЬ** - він показується тільки один раз!

### Крок 3: Додайте App Password в .env.local

1. Відкрийте файл `designer-bags-ua/.env.local`
2. Знайдіть рядок:
   ```env
   GMAIL_APP_PASSWORD=YOUR_GMAIL_APP_PASSWORD_HERE
   ```
3. Замініть `YOUR_GMAIL_APP_PASSWORD_HERE` на скопійований пароль (БЕЗ пробілів):
   ```env
   GMAIL_APP_PASSWORD=abcdefghijklmnop
   ```

**ВАЖЛИВО:** Видаліть всі пробіли з пароля!

### Крок 4: Перевірте налаштування

Ваш файл `.env.local` повинен містити:

```env
# Gmail SMTP Configuration (Nodemailer)
GMAIL_USER=knitt.lyelya531@gmail.com
GMAIL_APP_PASSWORD=ваш_app_password_без_пробілів
```

## Як працює відправка email

### 1. Email власнику при створенні замовлення
- **Коли:** При створенні будь-якого замовлення
- **Кому:** `knitt.lyelya531@gmail.com` (ваша пошта)
- **Тема:** "🛍️ Нове замовлення #..."
- **Містить:** інформацію про покупця, товари, доставку, спосіб оплати

### 2. Email клієнту після успішної оплати
- **Коли:** Після успішної оплати через Monobank (webhook зі статусом "success")
- **Кому:** Email клієнта з замовлення
- **Тема:** "✅ Оплата підтверджена - Замовлення #..."
- **Містить:** підтвердження оплати, деталі замовлення, інформацію про доставку

## Переваги Gmail SMTP (Nodemailer)

✅ **Безкоштовно:** Gmail дозволяє до 500 emails/день
✅ **Надійно:** Gmail має високу доставність
✅ **Просто:** Не потрібна реєстрація на сторонніх сервісах
✅ **Знайомо:** Використовуєте існуючий Gmail акаунт

## Обмеження Gmail

- **Ліміт:** 500 emails/день (більше ніж достатньо для інтернет-магазину)
- **Потрібен 2FA:** Необхідна двофакторна автентифікація
- **App Password:** Потрібен окремий пароль (не основний пароль Gmail)

## Troubleshooting

### Помилка: "Invalid login: 535-5.7.8 Username and Password not accepted"

**Причини:**
1. App Password неправильний або містить пробіли
2. 2FA не увімкнена
3. Використовується звичайний пароль замість App Password

**Рішення:**
1. Перевірте, що в `.env.local` немає пробілів в `GMAIL_APP_PASSWORD`
2. Перевірте, що 2FA увімкнена: https://myaccount.google.com/security
3. Створіть новий App Password
4. Перезапустіть сервер після зміни `.env.local`

### Помилка: "Gmail credentials не налаштовано"

**Причина:** Змінні `GMAIL_USER` або `GMAIL_APP_PASSWORD` відсутні в `.env.local`

**Рішення:**
1. Перевірте файл `.env.local`
2. Додайте обидві змінні
3. Перезапустіть сервер

### Email не приходить

**Перевірте:**
1. **Логи сервера:** Дивіться консоль на помилки
2. **Спам:** Перевірте папку "Спам" в email
3. **Email адреса:** Переконайтеся, що email клієнта правильний
4. **Gmail квота:** Перевірте, що не перевищили ліміт 500 emails/день

### Email йде в спам

**Рішення:**
1. Додайте `knitt.lyelya531@gmail.com` в контакти клієнта
2. Попросіть клієнтів позначити як "Не спам"
3. Для професійного вигляду розгляньте використання власного домену (Google Workspace)

### Не знаходжу "Паролі додатків" (App Passwords)

**Можливі причини:**
1. 2FA не увімкнена
2. Використовується Google Workspace з обмеженнями
3. Потрібно зачекати після увімкнення 2FA

**Рішення:**
1. Переконайтеся, що 2FA увімкнена
2. Спробуйте пряме посилання: https://myaccount.google.com/apppasswords
3. Зачекайте 10-15 хвилин після увімкнення 2FA
